# LX Music 无障碍版 - 完整键盘导航指南

## 🎯 键盘导航概览

### 主窗口与工具窗口

主窗口只保留四个音乐浏览页面：`Ctrl+1` 搜索、`Ctrl+2` 播放列表、`Ctrl+3` 分类歌单、`Ctrl+4` 排行榜。正在播放信息和状态栏位于页面集合之外。`Ctrl+5` 到 `Ctrl+8` 依次打开下载管理、导入个人歌单、音源管理和设置；歌词窗口不使用数字切换。

按 `Alt+T` 打开顶部“工具”菜单。菜单按顺序提供：工具→下载管理、工具→导入个人歌单、分隔线、工具→音源管理、工具→设置；浏览等其他菜单不重复提供这些入口。工具窗口都可用 `Esc` 或 `Alt+F4` 关闭：设置为模态窗口，其他工具窗口为非模态窗口。导入窗口处于歌曲预览时，第一次 `Esc` 返回歌单列表；设置正在录制快捷键时，第一次 `Esc` 取消录制。

设置窗口使用左侧类别列表和右侧内容，七类依次为：常规、播放、歌词、下载、存储与缓存、无障碍、快捷键。方向键切换类别并留在列表，`Tab` 进入右侧，`Shift+Tab` 返回类别列表。音源管理和下载管理打开后始终聚焦其核心列表，即使列表为空。

### 歌单页键盘导航

#### Tab键导航顺序：
1. **音乐源选择器** (Tab + 1) - 选择不同的音乐站点
2. **刷新按钮** (Tab + 2) - 刷新当前音乐源的歌单
3. **分类列表** (Tab + 3) - 浏览歌单分类
4. **歌单列表** (Tab + 4) - 浏览具体歌单
5. **歌曲列表** (Tab + 5) - 浏览歌单中的歌曲（列表末尾自带"上一页/下一页"条目，方向键+回车翻页）

#### 排行榜页键盘导航

#### Tab键导航顺序：
1. **音乐源选择器** (Tab + 1) - 选择不同的音乐站点
2. **刷新按钮** (Tab + 2) - 刷新当前音乐源的排行榜
3. **排行榜列表** (Tab + 3) - 浏览不同排行榜
4. **歌曲列表** (Tab + 4) - 浏览排行榜中的歌曲（列表末尾自带"上一页/下一页"条目，方向键+回车翻页）

## ⌨️ 详细快捷键说明

### 通用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 移动到下一个控件 |
| `Shift+Tab` | 移动到上一个控件 |
| `Ctrl+R` | 刷新当前页面数据 |
| `Esc` | 隐藏窗口到系统托盘（搜索页有内容时先清空搜索框） |
| `Alt+F4` | 关闭应用或隐藏到托盘（可在设置中配置） |
| `Ctrl+Alt+J` | 歌词延后 0.5 秒（修正歌词提前朗读） |
| `Ctrl+Alt+K` | 歌词提前 0.5 秒 |

### 局部快捷键（主窗口或工具窗口聚焦时生效，可在工具→设置→快捷键中修改）

编辑文本或录制快捷键时，局部播放快捷键会暂停，避免截获输入。

| 快捷键 | 功能 |
|--------|------|
| `F5` | 播放/暂停 |
| `F6` | 停止 |
| `F7` | 快退十秒 |
| `F8` | 快进十秒 |
| `F9` | 音量减 |
| `F11` | 上一个播放设备 |
| `F12` | 下一个播放设备 |
| `Shift+F7` | 歌词延后 0.5 秒 |
| `Shift+F8` | 歌词提前 0.5 秒 |
| `F1` | 切换播放模式（顺序/循环/随机） |
| `F2` | 下载当前歌曲 |
| `F3` | 上一首 |
| `F4` | 下一首 |

### 播放控制菜单
播放控制已从右侧面板移入 Alt 菜单栏的“播放(_P)”菜单：
播放/暂停、停止、上一首、下一首、快退十秒、快进十秒、音量减、音量加、
上一个播放设备、下一个播放设备、歌词延后、歌词提前、播放模式、下载。
文件菜单新增“隐藏/显示窗口”。

歌词时间偏移说明：若某首歌的歌词朗读始终偏早/偏晚（常见于 AI 生成歌词或不同版本），可用 Ctrl+Alt+J（延后）/ Ctrl+Alt+K（提前） 逐次 0.5 秒微调该歌曲的歌词时间偏移。
调整会按歌曲记忆，下次播放自动生效；也可在工具→设置→快捷键中修改这两个按键。

### 系统托盘
- 主窗口与打开的工具窗口组成窗口组；主窗口按 Esc 隐藏到托盘时，当前可见成员一同隐藏，音乐继续播放。
- 双击托盘图标恢复隐藏前可见的窗口及原焦点；托盘右键菜单：显示主窗口、播放/暂停、上一首、下一首、退出。
- 退出程序请用托盘菜单“退出”或打开主窗口后按 文件→退出。

### 控件内快捷键

#### 音乐源选择器
- `↑/↓` 箭头键 - 浏览不同的音乐源
- `Enter` - 确认选择音乐源
- `Home/End` - 跳转到第一个/最后一个音乐源

#### 列表控件（分类、歌单、排行榜、歌曲）
- 程序进入非空列表时直接聚焦当前选中项；没有有效选择时从第一项开始。空列表仍聚焦列表本身。后台刷新不会把已移开的焦点抢回。
- `↑/↓` 箭头键 - 浏览列表项
- `Enter` - 选择当前项（播放歌曲或选择分类/歌单/排行榜）
- `Space` - 播放当前歌曲（仅歌曲列表）
- `Home/End` - 跳转到第一项/最后一项
- `Page Up/Down` - 上一页/下一页

#### 搜索框
- `↑/↓` 箭头键 - 浏览搜索历史（最近 20 条，回车即可再次搜索）
- `Ctrl+Delete` - 删除当前搜索记录
- `Alt+Delete` - 清空全部搜索历史
- `Enter` - 开始搜索

#### 按钮
- `Enter` 或 `Space` - 激活按钮
- `Alt+字母` - 使用快捷键激活按钮（如 `Alt+R` 激活刷新按钮）

## 🎵 音乐播放操作

### 播放歌曲的方法：
1. **双击** 歌曲项（鼠标操作）
2. **Enter键** 选择歌曲
3. **Space键** 选择歌曲
4. 在歌曲列表中选中后按 Enter 或 Space

### 音乐源切换：
1. 使用 `Tab` 键导航到音乐源选择器
2. 使用 `↑/↓` 箭头键选择不同的音乐源
3. 按 `Enter` 确认切换

- 普通控件不添加冗余 HelpText 或描述，避免读屏噪音
- 支持键盘导航和操作
- 语义化标签提升可访问性

- 会提供操作提示和帮助信息
- 支持快速导航和操作

## 🔍 使用示例

### 示例1：切换音乐源并播放歌曲
```
1. 按 Tab 键导航到音乐源选择器
2. 使用 ↑/↓ 键选择"QQ音乐"
3. 按 Enter 确认切换
4. 连续按 Tab 键直到聚焦到歌曲列表
5. 使用 ↑/↓ 键选择歌曲
6. 按 Enter 或 Space 播放歌曲
```

### 示例2：快速操作流程
```
1. 按 Alt+M 快速聚焦音乐源选择器
2. 选择音乐源后按 Enter
3. 按 Alt+C 聚焦分类列表（歌单页）
4. 选择分类后按 Enter
5. 按 Alt+S 聚焦歌曲列表
6. 选择歌曲并播放
```

## 🎵 整列表连续播放
- 在任意歌曲列表（搜索、歌单、排行榜、播放列表、收藏）播放某首歌曲后，
  会自动以整个列表为播放队列，播完自动播放下一首。
- “上一首/下一首”快捷键在整个列表内切换。
- 右键菜单“从当前歌曲播放整个列表”：从当前歌曲开始顺序播放整张列表。

## ⭐ 本地收藏与在线收藏
- 播放列表页分两个选项卡：“本地收藏”与“在线收藏”。
- 本地收藏：添加文件/文件夹写入当前选中的本地歌单（默认“我的本地歌曲”），
  支持新建/重命名/删除歌单与导出 .m3u/.json/.txt；数据自动保存。
- 在线收藏：收藏单曲或整个列表到当前选中的在线歌单（默认“默认收藏”），
  支持新建/重命名/删除/清空歌单；歌曲右键“收藏整个歌单到在线收藏”可把
  分类歌单/排行榜整单收藏（打开时按需联网加载）。
- 歌单列表底部预留“导入QQ/酷狗/酷我个人歌单”入口，后续版本开发。
- 旧版“网络歌曲收藏”数据会自动迁移进“默认收藏”歌单。

## 🆘 故障排除

### 问题：Tab键无法导航
- 解决：确保焦点在窗口内，点击窗口任意位置

### 问题：快捷键不工作
- 解决：确保输入法为英文模式，检查是否有其他程序占用快捷键

### 问题：列表操作无响应
- 解决：确保列表中有数据，尝试刷新页面

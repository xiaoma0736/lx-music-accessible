# 键盘导航指南（落雪音乐无障碍版 3.0）

本指南只描述当前原生 WinForms 界面实际存在的按键与行为。全部功能都能只用键盘完成，不需要鼠标；界面尺寸与系统字体缩放（100%、150%、200%）都不会改变按键含义。

## 一、总览

- 主窗口只有一个菜单栏、一个四页选项卡、一条播报行和底部状态区。四个音乐页面：`Ctrl+1` 搜索、`Ctrl+2` 播放列表、`Ctrl+3` 分类歌单、`Ctrl+4` 排行榜。“正在播放”信息与状态栏不属于任何页面。
- 四个工具命令：`Ctrl+5` 到 `Ctrl+8` 依次打开工具→下载管理、工具→导入个人歌单、工具→音源管理、工具→设置。也可按 `Alt+T` 打开“工具”菜单，顺序同样是工具→下载管理、工具→导入个人歌单、分隔线、工具→音源管理、工具→设置，没有其他重复入口。
- 歌词窗口用 `Shift+回车`（任意歌曲列表）或“导航→歌词”打开，不占用数字键。
- 所有工具窗口都能用原生标题栏、`Esc` 或 `Alt+F4` 关闭，内容区不另设“关闭”按钮。每类工具窗口同时只存在一个：再次执行同一个命令会把已打开的窗口带到前台，而不会复制出一个同名窗口。

## 二、菜单栏

- 按 `Alt` 或 `F10` 之外的方式进入菜单栏：单独按 `Alt` 后，用左右方向键在顶级菜单之间移动，上下方向键展开并浏览，回车执行，`Esc` 退出菜单。
- 顶级菜单的访问键是可按的 ASCII 字母：`Alt+F` 文件、`Alt+B` 播放、`Alt+D` 导航、`Alt+T` 工具、`Alt+H` 帮助。菜单文字写作“文件(&F)”这种形式，因为把 `&` 放在中文上产生的访问键无法按下。
- 展开某个菜单后，菜单项括号里的字母是其访问键（例如“播放”菜单里“停止(&S)”按 `S`）。
- 菜单项右侧显示的按键（例如“停止(&S)  F6”）是局部快捷键，不必打开菜单即可直接按。
- 本应用默认把 `F10` 用作“音量加”，因此单独按 `F10` 不打开菜单；`Alt+F10` 仍按 Windows 习惯进入菜单栏。可在“工具→设置→快捷键”中把“音量加”改到别的键。

## 三、页面切换与“明确命令才加载”

- `Ctrl+1` 到 `Ctrl+4`、“导航”菜单、`Alt+C`/`Alt+P`/`Alt+R` 和 `Ctrl+上`/`Ctrl+下` 都会打开目标页并加载这一页的首层数据。
- `Ctrl+R` 重新加载当前页；各页也有“刷新”按钮，含义相同。
- 在标签头上用左右方向键或 `Ctrl+Tab` 移动焦点只是移动焦点：不发请求、不清空列表、不播报。若这样进入了尚未加载的页面，请按 `Ctrl+R` 或页内“刷新”按钮明确加载。
- 设置窗口顶部的“设置分类”选项卡同理：切换分类只换可见页面，不保存、不联网。

## 四、列表内按键

适用于搜索、专辑、分类歌单、分类歌曲、排行榜、榜单歌曲、收藏歌曲等原生列表：

| 按键 | 作用 |
| --- | --- |
| `↑`/`↓` | 逐项浏览，读屏器朗读整行内容 |
| `Home`/`End`、`PageUp`/`PageDown` | 跳到首项/末项、上下翻页 |
| `回车` 或双击 | 执行该项：播放歌曲，或展开分类/歌单/榜单/专辑的下一层 |
| `空格` | 播放/暂停（仅歌曲列表） |
| `Shift+回车` | 查看当前歌曲的歌词 |
| 应用键 / `Shift+F10` | 打开歌曲菜单：播放、歌词、详情、收藏、下载当前歌曲、下载单曲音质、播放音质、下载整张专辑、批量选择下载、切换音源播放、第三方播放 |
| `Backspace` | 返回上一级列表，焦点回到原来的上层条目 |
| 列表末尾“加载更多”条目 + `回车` | 追加下一页；到最后一页后该条目自动消失 |
| `Delete`（“我的歌单”项上） | 不执行删除；删除歌单要用页顶“删除歌单”按钮 |

- 歌曲列表保持单选。在歌曲列表按 `空格`：正在播放则暂停，已暂停则继续；没有当前歌曲时播放焦点歌曲。批量窗口中的 `空格` 只勾选，不播放。
- 成功追加“加载更多”后，焦点和朗读光标移动到本次新增的第一首；刷新替换、失败或没有新增时不移动。
- “批量选择下载”打开独立 `CheckedListBox` 窗口。窗口内 `空格` 勾选/取消当前行，`Ctrl+A` 全选，“清空”取消全部；状态行显示“已选择 N 首”。必须按“下载选中歌曲”才创建批量任务，使用设置中的默认下载音质。关闭后焦点返回发起列表。
- “播放音质”只探测当前默认音源能提供的音质（默认音源不支持当前歌曲平台时回退到该平台的全部接口），在音源管理改默认音源后立即生效；“切换音源播放”仍列出所有接口，只显示解析到可播放链接的候选，状态行报告“找到 N 个可播放音源，已隐藏 M 个不可用项”，回车用选中的音源与音质精确播放。
- 选中列表项本身不加载数据、不播放、不删除，一切都要由上面的明确命令触发。
- “加载更多”按钮本身不在 Tab 顺序里（`TabStop = false`），它的键盘入口就是列表末尾的同名条目，避免同一命令出现两个焦点目标。
- 空列表也会获得并保持焦点，后台刷新不会把焦点从你所在的位置抢走；只有下载管理的任务按钮在任务状态变化后变为不可用时，焦点才会回到任务列表（因为不可用的控件无法保持焦点）。

## 五、局部快捷键（仅本程序内生效，可在“工具→设置→快捷键”中修改）

| 按键 | 功能 |
| --- | --- |
| `F5` | 播放/暂停 |
| `F6` | 停止 |
| `F3` / `F4` | 上一首 / 下一首 |
| `F7` / `F8` | 快退十秒 / 快进十秒 |
| `F9` / `F10` | 音量减 / 音量加 |
| `F11` / `F12` | 上一个 / 下一个播放设备 |
| `Shift+F7` / `Shift+F8` | 歌词延后 0.5 秒 / 提前 0.5 秒（按歌曲记忆） |
| `F1` | 切换播放模式（顺序/列表循环/单曲循环/随机） |
| `F2` | 下载当前歌曲 |
| `Ctrl+上` / `Ctrl+下` | 在四个页面之间切换并加载 |
| `Ctrl+R` | 重新加载当前页 |
| `Alt+M` | 打开搜索页并聚焦“搜索音源” |
| `Alt+C` | 打开分类歌单页 |
| `Alt+P` | 打开播放列表页 |
| `Alt+S` | 聚焦当前页的歌曲列表 |
| `Alt+R` | 打开排行榜页并聚焦“排行榜”列表 |
| `应用键` / `Shift+F10` | 打开当前列表的菜单 |
| `Esc` | 搜索框有内容时清空搜索；否则把主窗口隐藏到系统托盘 |

- 在可编辑的文本框里输入时，局部快捷键不会触发命令，避免打字误操作；`Esc` 与各窗口自己的按键仍照常。
- 本程序不占用 `Ctrl+H`（文本框中删除前一个字符的通用按键）；隐藏/显示窗口的默认全局键是 `Ctrl+Alt+H`。

## 六、全局快捷键（后台也可用，可在“工具→设置→快捷键”中修改）

| 按键 | 功能 |
| --- | --- |
| `Ctrl+Alt+Home` | 播放/暂停 |
| `Ctrl+Alt+End` | 停止 |
| `Ctrl+Alt+PageUp` / `Ctrl+Alt+PageDown` | 上一首 / 下一首 |
| `Ctrl+Alt+Left` / `Ctrl+Alt+Right` | 快退 / 快进 |
| `Ctrl+Alt+Up` / `Ctrl+Alt+Down` | 音量加 / 音量减 |

注册失败时（例如被其他程序占用）会明确播报哪些快捷键没有生效，不会静默失灵。

## 七、各窗口的焦点与操作

- **主窗口**：打开后焦点在“搜索”页的搜索框。`Tab` 顺序为音源/类型下拉框 → 搜索框 → 搜索、清空按钮 → 结果列表；`Ctrl+F` 直接聚焦搜索框，搜索框内 `↑`/`↓` 浏览最近 20 条历史，`回车` 搜索并把焦点移到结果列表，`Ctrl+Delete` 删除当前记录，`Alt+Delete` 清空全部。
- **播放列表页**：左侧“我的歌单”，右侧“收藏歌曲”。`回车` 把所选歌单的歌曲读进右侧；页顶按钮依次是新建歌单、重命名歌单、删除歌单、刷新、移除歌曲、清空歌曲，都要先用 `Tab` 到达再按 `回车` 执行，焦点经过时不会自动执行。
- **分类歌单页**：音源下拉框 →“刷新”→“分类”列表（`回车` 加载歌单）→“歌单”列表（`回车` 加载歌曲，应用键菜单“收藏整个歌单到在线收藏”）→“分类歌曲”列表。
- **排行榜页**：音源下拉框 →“刷新”→“排行榜”列表（`回车` 加载歌曲，应用键菜单“收藏整个榜单到在线收藏”）→“排行榜歌曲”列表。
- **下载管理**：`Ctrl+5` 打开，任务列表即使为空也始终获得初始焦点；`回车` 不启动任何下载。按钮为“取消”“重试”“打开文件夹”“清除已完成”，可用性随所选任务状态变化。
- **导入个人歌单**：`Ctrl+6` 打开。平台按钮会先检测已保存登录：有效时直接进入“个人歌单”列表；无登录或失效时打开“登录方式”列表（`回车` 或“使用所选方式”确认，`Esc` 取消并回到该平台按钮）→ 粘贴 Cookie 时聚焦 Cookie 输入框；网页登录会自动检测登录状态并在平台确认后关闭、随后自动加载歌单（浏览器里已登录过该平台时，打开后两三秒即自动确认），需要时用“完成登录”或“刷新页面”重试，换账号按“清除登录记录”；酷狗扫码用“刷新二维码”重试→“个人歌单”列表（`回车` 预览）→“歌曲预览”列表（`回车` 播放、`Shift+回车` 看歌词、应用键打开歌曲菜单）。“导入当前歌单”一次导入整张远程歌单，界面不提供按所选歌曲导入的命令。预览层第一次按 `Esc` 返回歌单列表，再按 `Esc` 才关闭窗口。
- **音源管理**：`Ctrl+7` 打开，音源列表获得初始焦点。应用键、`Shift+F10` 或在列表上按 `回车`/`空格` 弹出操作菜单：设为默认、启用、禁用、测试、检查更新、删除；删除需要明确确认。
- **设置**（`Ctrl+8`，模态）：顶部“设置分类”选项卡，七类依次为：常规、播放、歌词、下载、存储与缓存、无障碍、快捷键。在选项卡上按 `Tab` 进入当前分类的内容，`Shift+Tab` 回到选项卡；方向键与 `Ctrl+Tab` 切换分类不会保存或联网。普通修改立即生效；第三方播放器路径与下载目录只在 `Enter` 或关闭窗口时写入，移动焦点不写入；“无障碍”页的朗读语音与语速改动立即生效并在下次启动恢复所选语音；“语音提示范围”分组中的播放状态、切歌播报、音量变化、快进快退位置、窗口显隐、播放模式和播放设备复选框可单独开关朗读范围，改动立即保存。快捷键页：列表中选择一项后按 `回车` 或 `空格` 开始录制，`Delete` 清除，录制中第一次按 `Esc` 只取消录制。
- **歌词窗口**：`Shift+回车` 或“导航→歌词”打开。歌词区是全文文本查看器，句首没有序号；当前句按“设置→歌词→自动滚动歌词”决定是否以选中方式标记并滚动跟随（关闭时保留手动阅读位置），`↑`/`↓`、`PageUp`/`PageDown` 可逐行浏览，`Ctrl+Shift+C` 或“复制歌词”按钮复制全文，`Esc` 关闭。同一时间只有一个歌词窗口。
- **使用说明窗口**：“帮助→使用说明”。用“指南章节”下拉框切换章节，正文区紧随其后按 `Tab` 即可阅读，末尾是“关闭”按钮，`Esc` 也可关闭。
- **所有对话框**：`回车` 执行默认按钮，`Esc` 或 `Alt+F4` 取消；确认类操作默认停在“否”，需要明确选择“是”。

## 八、系统托盘

- 主窗口按 `Esc` 隐藏到托盘时，当前可见的工具窗口作为同一窗口组一起隐藏，音乐继续播放；双击托盘图标恢复这些窗口与主窗口。
- 托盘菜单（应用键或右键）提供：显示主窗口（`Alt+S`）、播放/暂停（`Alt+P`）、上一首（`Alt+V`）、下一首（`Alt+N`）、退出（`Alt+X`）；菜单打开后用这些访问键即可选择项目。只有“退出”或“文件→退出”（`Ctrl+Q`）才结束程序。

## 九、朗读策略：什么会读，什么不读

- 读屏器自己负责的内容不重复朗读：焦点控件名称、列表项整行文本、下拉框的新选项、新聚焦的列表。
- 默认会朗读：正在播放与播放失败、暂停/停止/恢复、切歌、快进快退位置、音量、窗口显隐、播放队列完成、播放模式、播放设备、下载开始与结果、收藏与导入结果、登录与设置结果、快捷键录制与注册失败、错误提示、逐句歌词（开启后）。
- 固定保持安静：页面加载回显、返回上级列表、使用说明的章节切换、欢迎语，以及音源管理窗口自己执行命令后补发的“音源列表已更新”回显（命令已经报过一次结果）。播放状态、切歌、音量、快进快退、窗口显隐、播放模式和播放设备可在“设置→无障碍→语音提示范围”单独关闭。
- 每条朗读同时写入底部状态区与一个可再次读取的区域，错过的信息可以用读屏器的复读快捷键重新阅读。
- “工具”菜单里的“语音播报”“歌词播报”是带勾选的状态项，`Alt+T` 后按 `V` 或 `L` 即可开关。“语音播报”是除逐句歌词以外全部提示的总开关，逐句歌词只由“歌词播报”控制；“设置→无障碍→语音提示范围”再按类别收窄。每条提示同时显示在主窗口页面下方的播报行，关闭朗读后仍可用读屏器的审阅光标查看。

## 十、实现约定（改动界面时请保持）

- 每个可聚焦控件都显式声明 `TabIndex`，同一容器内不重复；纯容器与展示用标签 `TabStop = false`，不进入 Tab 顺序。
- 控件的 `AccessibleName` 只写语义名称，不含“按钮”“列表”等角色词，也不写教学式 `HelpText`/`AccessibleDescription`。
- 动态文本（状态栏、正在播放、空列表提示、导入状态等）不设固定的 `AccessibleName`，让它朗读自己的 `Text`。
- 主菜单用 `MainMenu` + `MenuItem`，右键与弹出菜单用 `ContextMenu` + `MenuItem`。
- 焦点移动不触发联网、播放、删除等副作用；后台更新保留或明确恢复焦点。

# LX Music 无障碍版 - 需求与发布说明

## 项目概述
基于开源项目 lx-music-desktop，使用 C#、.NET Framework 4.8 与原生 WinForms 开发的专为盲人和视障用户优化的 64 位 Windows 客户端。

## 3.0.0 运行环境与发布

- 产品版本为 3.0.0，仅支持 64 位 Windows。
- 应用为框架依赖版本，必须已安装 Microsoft .NET Framework 4.8 或更新版本（安装器检查注册表 Release 值不低于 `528040`）。
- ZIP 不内置 .NET 运行时；安装器会检测运行时，缺失时给出官方下载地址和诊断文件路径。
- 网页登录使用 Microsoft Edge WebView2 Runtime；歌词/状态语音播报可使用 SAPI5，检测到争渡、保益或 Prism 后端时优先使用。
- 音频、SQLite、ClearScript V8、UIA/读屏桥接和 WebView2 加载器所需的 x64 原生库随应用分发；ClearScript V8 不可用时会回退到 Jint。
- 不提供应用 self-contained .NET 8 产物。数据默认继续使用 `%LocalAppData%\lxmusic`，升级保留设置、歌单、凭据、快捷键和可信音源。

完整发布验证、产物哈希和人工验收状态见 [docs/release-validation-3.0.0.md](docs/release-validation-3.0.0.md)。

## 当前界面与键盘入口

主窗口只包含搜索、播放列表、分类歌单、排行榜四个页面，以及页面外的播报行和底部正在播放/状态信息。`Ctrl+1` 到 `Ctrl+4` 依次切换四页；`Ctrl+5` 到 `Ctrl+8` 依次打开下载管理、导入个人歌单、音源管理和设置（歌词窗口除外）。

四个独立功能只从顶部工具菜单进入，顺序为：工具→下载管理、工具→导入个人歌单、分隔线、工具→音源管理、工具→设置。只有设置是模态窗口，下载管理、导入个人歌单、音源管理和歌词是主窗口的非模态子窗口；每类工具窗口同时只打开一个，重复命令把已有窗口带到前台（歌词与切换音源还会把新选的歌曲载入该窗口）。工具窗口使用原生标题栏、`Esc` 或 `Alt+F4` 关闭。音源管理和下载管理始终把焦点放在核心列表，即使列表为空。菜单栏访问键为 Alt+F/B/D/T/H；默认把 F10 用作“音量加”，因此 F10 不打开菜单，可在“工具→设置→快捷键”改键。

歌曲浏览列表使用单选模式。在歌曲列表按 `空格` 时：正在播放则暂停；已暂停则继续；当前没有歌曲则播放焦点歌曲。四个歌曲列表成功追加“加载更多”后，焦点和读屏光标移动到新增的第一首。歌曲右键菜单提供下载单曲音质/播放音质、整张专辑下载（仅专辑上下文）和“批量选择下载”。批量选择下载”。`F2` 可按当前播放音质下载当前播放歌曲。批量选择在独立窗口中用 `空格` 勾选，勾选状态不影响主列表播放；专辑和批量下载使用设置中的“默认下载音质”。

设置窗口以顶部原生选项卡“设置分类”分组，顺序为：常规、播放、歌词、下载、存储与缓存、无障碍、快捷键。播放分类同时包含外部播放器和四值默认播放模式。在选项卡上按方向键切换分类、`Tab` 进入内容、`Shift+Tab` 返回分类；普通打开总是从常规开始。路径输入框只在按 `Enter` 或关闭窗口时写入设置，移动焦点不写入。“无障碍”分类的朗读语音保存的是语音标识，改动立即生效并在下次启动恢复同一语音；语音提示范围用复选框单独控制播放状态、切歌、音量、快进快退、窗口显隐、播放模式和播放设备，默认全部开启。

## 核心需求

### 1. 屏幕阅读器无障碍键盘导航
- **全局快捷键支持**：空格/Enter 播放暂停、方向键选择、Tab 切换焦点
- **目标读屏器**：NVDA、Narrator、JAWS 等主流屏幕阅读器；人工读屏验收在发布前执行
- **UI Automation 支持**：WinForms 控件暴露语义名称和状态，通知由 TTS 输出
- **语音提示**：高价值操作结果与错误提供语音反馈，常规加载提示保持静音；“语音播报”是除逐句歌词外所有提示的总开关，播放状态、切歌、音量、快进快退、窗口显隐、播放模式和播放设备还可按范围勾选，每条提示同时写入主窗口底部的播报行，供读屏器审阅光标或放大工具查看
- **焦点管理**：确保焦点位置准确、可预测，焦点切换路径合理

### 2. 分页式视图展示

#### 2.1 搜索功能
- 支持多平台搜索（网易云、QQ音乐、酷狗、酷我、咪咕）
- 分页显示搜索结果（20条/页）
- 支持按歌曲、歌手、专辑分类显示
- 快速预览和播放搜索结果

#### 2.2 分类歌单浏览

- 打开分类歌单页时自动加载当前平台的官方分类；选择分类后按回车加载歌单列表。
- 支持网易云、QQ音乐、酷狗、酷我、咪咕五个官方平台的分类动态浏览
- 按音乐类型分类（流行、摇滚、古典、民谣等）
- 按情感分类（治愈、励志、怀旧等）
- 按场景分类（工作、学习、运动、睡眠等）
- 分页展示，支持快速跳转

#### 2.3 排行榜查看

- 打开排行榜页时自动加载当前平台的榜单列表；选择榜单后按回车加载歌曲。
- 热歌榜、新歌榜、原创榜等主流排行榜
- 支持网易云、QQ音乐、酷狗、酷我、咪咕五个平台
- 分页显示，可查看历史排行

#### 2.4 个人列表管理
- **本地文件支持**：添加本地音频文件到个人歌单
- **文件夹支持**：添加整个文件夹的音乐到个人歌单
- **云同步**：支持歌单云端同步（可选）
- **导入导出**：支持歌单导入导出功能
- **标签管理**：为歌单添加标签，便于分类管理

### 3. 歌词查看功能

#### 3.1 文本查看器模式
- 逐句显示歌词，当前播放句子高亮
- 支持上下翻页浏览歌词
- 支持调整字体大小和颜色
- 支持中英文双语歌词

#### 3.2 同步朗读模式
- 调用 prism 接口实现歌词同步朗读
- 语音与播放进度实时同步
- 支持多种 TTS 语音选择
- 可调节朗读速度和音调

### 4. 自定义快捷键系统

#### 4.1 局部快捷键
- 界面内各种功能的快捷键配置
- 不同视图可以有不同的快捷键设置
- 支持快捷键冲突检测

#### 4.2 全局快捷键
- 播放/暂停、上一首/下一首、音量调节
- 歌词开关、模式切换等核心功能
- 支持所有窗口下使用
- 快捷键组合灵活（Ctrl/Shift/Alt + 字母/数字/功能键）

#### 4.3 快捷键管理
- 导入导出快捷键配置
- 预设多套快捷键方案
- 快速切换不同快捷键方案

### 5. 免费音源集成

#### 5.1 预设音源接口
- **HYW 音乐（公益免费，内置）**：开箱即用，聚合 网易云/QQ音乐/酷狗/酷我/咪咕 的 128k/320k 播放 URL 解析（服务可能波动，播放时自动校验可播性并快速跳过失效源）。
- **免费脚本源预设**（启动自动加载，需联网）：HYW、聚合API、全豆要、念心（Jint 执行脚本，支持混淆源）。
- 其余音源请通过"从网络导入 / 从本地导入"自行添加；导入时自动校验脚本可执行。
- 第三方音源接口类型（musicUrl / lyric / pic 与 lx 运行时 API）详见 [docs/第三方音源接口.md](docs/第三方音源接口.md)。

#### 5.2 自定义音源接口
- **网络导入**：支持从 URL 导入音源脚本
- **本地导入**：支持从本地文件导入 JavaScript 音源脚本
- **音源测试**：导入前测试音源可用性
- **音源更新**：支持自动更新网络音源
- **音源管理**：启用/禁用/删除音源，调整优先级

## 最新增强（V1.2 无障碍版）

### 1. 整列表连续播放
在搜索、歌单、排行榜、播放列表、收藏等歌曲列表中播放任意歌曲后，会自动以整个
列表作为播放队列：歌曲播完自动播放下一首；“上一首/下一首”快捷键也在整个列表内
切换，不再只重复当前歌曲。歌曲右键菜单新增“从当前歌曲播放整个列表”。

### 2. 网络歌曲本地收藏
- 在搜索、歌单、排行榜的歌曲列表中，可用应用键/Shift+F10 打开操作菜单，将
  单曲“添加到收藏”，或将整个列表“添加整个列表到收藏”。
- 播放列表页新增“网络歌曲收藏”区，可浏览、播放、下载收藏的歌曲，支持
  “重命名收藏”“从收藏移除”“清空收藏”等编辑管理，收藏数据持久化保存。

### 3. 快捷键设置列表读屏优化
快捷键设置列表通过自定义自动化对等类把每个列表项设为“叶子节点”，读屏只朗读
一次（例如“播放/暂停：Ctrl+Alt+Home”只朗读一遍），不再重复朗读内部文本块。

### 4. 系统托盘
- 按 ESC 键把主窗口隐藏到系统托盘，音乐继续播放；双击托盘图标恢复。
- 托盘右键菜单：显示主窗口、播放/暂停、上一首、下一首、退出。
- “设置 → 播放设置”中可配置按 Alt+F4 时是“关闭应用”还是“隐藏到系统托盘”。

### 4. 小键盘方向键防误触
- 方向键热键组合（如 Alt+Shift+光标）不再被 NumLock 关闭时的小键盘 4/6/2/8 误触发。

## 最新增强（V2.4 无障碍版）
### 1. 在线播放改为“边下边播”+ 预缓存下一首
- 在线歌曲由“先整首下载再播放”改为 BASS 流式（边下边播），点播放后明显更快出声；个别链接建流失败自动回退下载。
- 播放某首歌时，后台自动把下一首解析并下载到临时文件；顺序连播/上一首/下一首切歌几乎无缝。
- 预缓存按“顺序/循环/随机”规则取下一首，队列变更自动取消并清理；本地歌曲无需预下载。
### 2. 修复切换播放设备后音量失效
- 原音量走“本程序会话音量”，切换非默认设备后会话音量不作用于该设备输出，导致数值在动但声音不变。
- 现改为：默认设备继续用会话音量（保留音量合成器双向跟随）；非默认设备改用 BASS 通道音量，音量真正生效。
### 3. 修复“导入个人歌单”选项卡焦点被抢
- 每次切到该标签时焦点不再被“获取我的歌单”按钮抢走，统一落到平台选择按钮，与其它标签行为一致。
### 4. 修复专辑超过 1500 首无法显示
- 专辑分页上限由 30 页（约 1500 首）提高到 200 页（约 10000 首），支持集数较多的有声专辑完整显示。
### 4. 修复专辑超过 1500 首无法显示
- 专辑分页上限由 30 页（约 1500 首）提高到 200 页（约 10000 首），支持集数较多的有声专辑完整显示。
### 5. 修复“切换播放设备提示失败”
- 播放中切换输出设备改用 BASS_ChannelSetDevice 直接把现有流搬到目标设备，保留缓冲与进度，不再重连/重新下载，
  流式播放中切设备也不再失败（默认设备使用其真实索引，具体设备按索引映射）。
### 6. 首曲播放提速
- 程序启动即预初始化 BASS（加载插件/配置/默认设备），消除第一首歌播放时的初始化耗时；
  网络预缓冲由 0.75 秒下调到 0.4 秒，首曲更快出声。
### 7. 修复“添加到收藏 / 添加整个列表到收藏”崩溃
- 根因：在线歌单数据的 Tags（文本列 ↔ List 模型）与 Type（整数列 ↔ 枚举模型）读取类型不匹配，
  导致收藏读取/创建时抛异常（首次收藏即崩溃）。现已解析/转换修复，收藏单曲与整个列表恢复正常。
### 8. 歌单列表新增“收藏整个歌单”
- 分类歌单列表、排行榜列表右键（应用键/Shift+F10）新增“收藏整个歌单/榜单到在线收藏”，无需先打开歌单即可收藏。
- 收藏做了去重：同一远程歌单已收藏时提示“已在在线收藏中”，避免重复。

## 最新增强（V2.1 无障碍版）
### 1. 全新 BASS 音频引擎
- 播放内核由 NAudio 更换为 BASS（un4seen，非商业免费；.NET 封装 ManagedBass，MIT 许可），
  音质更干净、解码更稳，显著降低高音量下的过载/爆音。
- 在线歌曲保持“先下载到临时文件再播放”，播放与快进/快退定位行为与之前完全一致；
  所有快捷键、播放队列、歌词同步、托盘、输出设备切换等操作习惯不变。
- 播放进度改用 BASS 精确解码位置，歌词与声音对齐更准。
- 本地格式支持增强：MP3/OGG/WAV/AAC/M4A/WMA 之外，新增 FLAC、APE、Opus。
### 2. 音量合成器双向同步保持不变
- 应用音量改由“本程序会话音量”承载：用快捷键调音量，Windows 音量合成器立即跟随；
  直接在合成器调整，程序内音量同步更新（切换设备、退出保存以合成器为准）。
- 音量增益走浮点处理，避免旧实现（waveOutSetVolume）在高增益下削波。

## 技术选型

### 核心技术栈
- **开发语言**：C#
- **运行时**：.NET Framework 4.8（x64，应用框架依赖）
- **UI 框架**：原生 WinForms
- **数据库**：SQLite（本地数据存储）
- **HTTP 客户端**：HttpClient
- **媒体播放**：BASS 及 APE/FLAC/Opus 插件
- **UI 自动化**：WinForms UI Automation 与原生通知

### 第三方库
- **依赖注入**：Microsoft.Extensions.DependencyInjection
- **日志记录**：Serilog
- **JSON 处理**：System.Text.Json
- **脚本引擎**：ClearScript V8 优先，Jint 回退
- **音频**：ManagedBass / BASS
- **网页登录**：WebView2
- **全局热键**：Win32 API
- **语音**：System.Speech 与 Prism/Tolk、争渡、保益桥接

## 无障碍设计原则

1. **键盘优先**：所有功能都可通过键盘完成
2. **语义化命名**：控件命名清晰、简洁、有意义
3. **焦点可见**：焦点变化时有明确的视觉和语音反馈
4. **操作可预测**：用户能预测操作结果
5. **错误处理友好**：错误信息清晰，提供解决方案
6. **自适应布局**：界面适应不同屏幕尺寸和缩放比例
7. **性能优化**：保证流畅的用户体验，减少等待时间

## 用户体验目标

- **学习成本低**：盲人用户能在 30 分钟内掌握基本操作
- **操作效率高**：常用操作 2-3 次按键即可完成
- **信息层次清晰**：界面结构简单，信息层次分明
- **反馈及时准确**：操作结果有明确的语音反馈
- **个性化程度高**：支持高度自定义的快捷键和界面设置

## 项目里程碑

1. **MVP 版本**：基础播放功能 + 无障碍键盘导航
2. **Alpha 版本**：分页视图 + 歌词查看 + 快捷键配置
3. **Beta 版本**：音源集成 + 完整无障碍优化
4. **正式版**：测试完善 + 用户文档 + 安装程序

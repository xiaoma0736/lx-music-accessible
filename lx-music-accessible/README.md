# LX Music 无障碍版 - 需求文档

## 项目概述
基于开源项目 lx-music-desktop，使用 C# + .NET 8.0 开发的专为盲人用户优化的 Windows 客户端。

## 核心需求

### 1. 完美支持屏幕阅读器的无障碍键盘导航
- **全局快捷键支持**：空格/Enter 播放暂停、方向键选择、Tab 切换焦点
- **屏幕阅读器兼容**：完美支持 NVDA、Narrator、JAWS 等主流屏幕阅读器
- **UI Automation 支持**：使用 UI Automation 框架提供完整的无障碍信息
- **语音提示**：操作状态变化时提供清晰的语音反馈
- **焦点管理**：确保焦点位置准确、可预测，焦点切换路径合理

### 2. 分页式视图展示

#### 2.1 搜索功能
- 支持多平台搜索（网易云、QQ音乐、酷狗等）
- 分页显示搜索结果（20条/页）
- 支持按歌曲、歌手、专辑分类显示
- 快速预览和播放搜索结果

#### 2.2 分类歌单浏览
- 按音乐类型分类（流行、摇滚、古典、民谣等）
- 按情感分类（治愈、励志、怀旧等）
- 按场景分类（工作、学习、运动、睡眠等）
- 分页展示，支持快速跳转

#### 2.3 排行榜查看
- 热歌榜、新歌榜、原创榜等主流排行榜
- 支持多平台排行榜
- 分页显示，可查看历史排行

#### 2.4 个人列表管理
- **本地文件支持**：添加本地音频文件到个人歌单
- **文件夹支持**：添加整个文件夹的音乐到个人歌单
- **云同步**：支持歌单云端同步（可选）
- **导入导出**：支持歌单导入导出功能
- **标签管理**：为歌单添加标签，便于分类管理

### 3. 歌词查看功能

#### 3.1 文本查看器模式
- 逐句显示歌词，当前播放句子高亮
- 支持上下翻页浏览歌词
- 支持调整字体大小和颜色
- 支持中英文双语歌词

#### 3.2 同步朗读模式
- 调用 prism 接口实现歌词同步朗读
- 语音与播放进度实时同步
- 支持多种 TTS 语音选择
- 可调节朗读速度和音调

### 4. 自定义快捷键系统

#### 4.1 局部快捷键
- 界面内各种功能的快捷键配置
- 不同视图可以有不同的快捷键设置
- 支持快捷键冲突检测

#### 4.2 全局快捷键
- 播放/暂停、上一首/下一首、音量调节
- 歌词开关、模式切换等核心功能
- 支持所有窗口下使用
- 快捷键组合灵活（Ctrl/Shift/Alt + 字母/数字/功能键）

#### 4.3 快捷键管理
- 导入导出快捷键配置
- 预设多套快捷键方案
- 快速切换不同快捷键方案

### 5. 免费音源集成

#### 5.1 预设音源接口
- **HYW 音乐（公益免费，内置）**：开箱即用，聚合 网易云/QQ音乐/酷狗/酷我/咪咕 的 128k/320k 播放 URL 解析（服务可能波动，播放时自动校验可播性并快速跳过失效源）。
- **免费脚本源预设**（启动自动加载，需联网）：HYW、聚合API、全豆要、念心（Jint 执行脚本，支持混淆源）。
- 其余音源请通过"从网络导入 / 从本地导入"自行添加；导入时自动校验脚本可执行。
- 第三方音源接口类型（musicUrl / lyric / pic 与 lx 运行时 API）详见 [docs/第三方音源接口.md](docs/第三方音源接口.md)。

#### 5.2 自定义音源接口
- **网络导入**：支持从 URL 导入音源脚本
- **本地导入**：支持从本地文件导入 JavaScript 音源脚本
- **音源测试**：导入前测试音源可用性
- **音源更新**：支持自动更新网络音源
- **音源管理**：启用/禁用/删除音源，调整优先级

## 最新增强（V1.2 无障碍版）

### 1. 整列表连续播放
在搜索、歌单、排行榜、播放列表、收藏等歌曲列表中播放任意歌曲后，会自动以整个
列表作为播放队列：歌曲播完自动播放下一首；“上一首/下一首”快捷键也在整个列表内
切换，不再只重复当前歌曲。歌曲右键菜单新增“从当前歌曲播放整个列表”。

### 2. 网络歌曲本地收藏
- 在搜索、歌单、排行榜的歌曲列表中，可用应用键/Shift+F10 打开操作菜单，将
  单曲“添加到收藏”，或将整个列表“添加整个列表到收藏”。
- 播放列表页新增“网络歌曲收藏”区，可浏览、播放、下载收藏的歌曲，支持
  “重命名收藏”“从收藏移除”“清空收藏”等编辑管理，收藏数据持久化保存。

### 3. 快捷键设置列表读屏优化
快捷键设置列表通过自定义自动化对等类把每个列表项设为“叶子节点”，读屏只朗读
一次（例如“播放/暂停：Ctrl+Alt+Home”只朗读一遍），不再重复朗读内部文本块。

### 4. 系统托盘
- 按 ESC 键把主窗口隐藏到系统托盘，音乐继续播放；双击托盘图标恢复。
- 托盘右键菜单：显示主窗口、播放/暂停、上一首、下一首、退出。
- “设置 → 播放设置”中可配置按 Alt+F4 时是“关闭应用”还是“隐藏到系统托盘”。

## 最新增强（V1.3 无障碍版）

### 1. 搜索历史
- 搜索框内按上/下光标循环查看最近 20 条搜索记录，回车即可再次搜索。
- Ctrl+Delete 删除当前显示的记录，Alt+Delete 清空全部；搜索历史自动保存。

### 2. NVDA 读屏语音保底
- 检测到 NVDA 读屏运行时，语音提示自动回退到 SAPI5，保证朗读始终可听
  （修复 NVDA 下 Prism 后端朗读不生效的问题）。

### 3. 音量合成器跟随
- 切换播放设备后用快捷键调节音量时，Windows 音量合成器会同步跟随当前音量值，
  不再出现“调到 100 合成器仍停留在旧值、需再次切换设备才恢复”的问题。

### 4. 小键盘方向键防误触
- 方向键热键组合（如 Alt+Shift+光标）不再被 NumLock 关闭时的小键盘 4/6/2/8 误触发。

## 最新增强（V1.5 无障碍版）

### 1. 导入个人歌单
- “播放列表→在线收藏”新增“导入个人歌单”入口，可一键导入账号下的个人歌单。
- 支持 网易云 / QQ音乐 / 酷狗 / 酷我 四个平台，内置“网页登录”（内嵌浏览器在软件内打开
  平台官网登录，自动检测登录状态并抓取 Cookie），另提供粘贴 Cookie 登录；
  登录后可获取“我喜欢的音乐”、我创建的歌单、我收藏的歌单，多选导入为本地快照歌单。
- 安全设计：登录凭据仅保存在本机，使用 Windows DPAPI 加密存储，
  请求直连各平台官方接口，不经过任何第三方服务器。

## 最新增强（V2.4 无障碍版）
### 1. 在线播放改为“边下边播”+ 预缓存下一首
- 在线歌曲由“先整首下载再播放”改为 BASS 流式（边下边播），点播放后明显更快出声；个别链接建流失败自动回退下载。
- 播放某首歌时，后台自动把下一首解析并下载到临时文件；顺序连播/上一首/下一首切歌几乎无缝。
- 预缓存按“顺序/循环/随机”规则取下一首，队列变更自动取消并清理；本地歌曲无需预下载。
### 2. 修复切换播放设备后音量失效
- 原音量走“本程序会话音量”，切换非默认设备后会话音量不作用于该设备输出，导致数值在动但声音不变。
- 现改为：默认设备继续用会话音量（保留音量合成器双向跟随）；非默认设备改用 BASS 通道音量，音量真正生效。
### 3. 修复“导入个人歌单”选项卡焦点被抢
- 每次切到该标签时焦点不再被“获取我的歌单”按钮抢走，统一落到平台选择按钮，与其它标签行为一致。
### 4. 修复专辑超过 1500 首无法显示
- 专辑分页上限由 30 页（约 1500 首）提高到 200 页（约 10000 首），支持集数较多的有声专辑完整显示。
### 4. 修复专辑超过 1500 首无法显示
- 专辑分页上限由 30 页（约 1500 首）提高到 200 页（约 10000 首），支持集数较多的有声专辑完整显示。
### 5. 修复“切换播放设备提示失败”
- 播放中切换输出设备改用 BASS_ChannelSetDevice 直接把现有流搬到目标设备，保留缓冲与进度，不再重连/重新下载，
  流式播放中切设备也不再失败（默认设备使用其真实索引，具体设备按索引映射）。
### 6. 首曲播放提速
- 程序启动即预初始化 BASS（加载插件/配置/默认设备），消除第一首歌播放时的初始化耗时；
  网络预缓冲由 0.75 秒下调到 0.4 秒，首曲更快出声。
### 7. 修复“添加到收藏 / 添加整个列表到收藏”崩溃
- 根因：在线歌单数据的 Tags（文本列 ↔ List 模型）与 Type（整数列 ↔ 枚举模型）读取类型不匹配，
  导致收藏读取/创建时抛异常（首次收藏即崩溃）。现已解析/转换修复，收藏单曲与整个列表恢复正常。
### 8. 歌单列表新增“收藏整个歌单”
- 分类歌单列表、排行榜列表右键（应用键/Shift+F10）新增“收藏整个歌单/榜单到在线收藏”，无需先打开歌单即可收藏。
- 收藏做了去重：同一远程歌单已收藏时提示“已在在线收藏中”，避免重复。
## 最新增强（V2.3 无障碍版）
### 1. 查看歌曲详情
- 任意歌曲列表右键菜单（应用键/Shift+F10）新增“查看歌曲详情”。
- 以列表逐条展示（读屏用上下方向键逐条浏览）：歌名、歌手、专辑、来源（网易云/QQ音乐/酷狗/酷我/咪咕/本地）、

### 1. 专辑详情显示全部歌曲

## 最新增强（V2.1 无障碍版）
### 1. 全新 BASS 音频引擎
- 播放内核由 NAudio 更换为 BASS（un4seen，非商业免费；.NET 封装 ManagedBass，MIT 许可），
  音质更干净、解码更稳，显著降低高音量下的过载/爆音。
- 在线歌曲保持“先下载到临时文件再播放”，播放与快进/快退定位行为与之前完全一致；
  所有快捷键、播放队列、歌词同步、托盘、输出设备切换等操作习惯不变。
- 播放进度改用 BASS 精确解码位置，歌词与声音对齐更准。
- 本地格式支持增强：MP3/OGG/WAV/AAC/M4A/WMA 之外，新增 FLAC、APE、Opus。
### 2. 音量合成器双向同步保持不变
- 应用音量改由“本程序会话音量”承载：用快捷键调音量，Windows 音量合成器立即跟随；
  直接在合成器调整，程序内音量同步更新（切换设备、退出保存以合成器为准）。
- 音量增益走浮点处理，避免旧实现（waveOutSetVolume）在高增益下削波。

## 技术选型

### 核心技术栈
- **开发语言**：C#
- **运行时**：.NET 8.0
- **UI 框架**：WPF（Windows Presentation Foundation）
- **数据库**：SQLite（本地数据存储）
- **HTTP 客户端**：HttpClient
- **媒体播放**：NAudio 或 MediaElement
- **UI 自动化**：UI Automation 框架

### 第三方库
- **MVVM 框架**：CommunityToolkit.Mvvm
- **依赖注入**：Microsoft.Extensions.DependencyInjection
- **日志记录**：Serilog
- **配置管理**：Microsoft.Extensions.Configuration
- **JSON 处理**：System.Text.Json
- **全局热键**：HotkeyManager 或 P/Invoke
- **TTS 集成**：System.Speech 或 Azure Speech Service

## 无障碍设计原则

1. **键盘优先**：所有功能都可通过键盘完成
2. **语义化命名**：控件命名清晰、简洁、有意义
3. **焦点可见**：焦点变化时有明确的视觉和语音反馈
4. **操作可预测**：用户能预测操作结果
5. **错误处理友好**：错误信息清晰，提供解决方案
6. **自适应布局**：界面适应不同屏幕尺寸和缩放比例
7. **性能优化**：保证流畅的用户体验，减少等待时间

## 用户体验目标

- **学习成本低**：盲人用户能在 30 分钟内掌握基本操作
- **操作效率高**：常用操作 2-3 次按键即可完成
- **信息层次清晰**：界面结构简单，信息层次分明
- **反馈及时准确**：操作结果有明确的语音反馈
- **个性化程度高**：支持高度自定义的快捷键和界面设置

## 项目里程碑

1. **MVP 版本**：基础播放功能 + 无障碍键盘导航
2. **Alpha 版本**：分页视图 + 歌词查看 + 快捷键配置
3. **Beta 版本**：音源集成 + 完整无障碍优化
4. **正式版**：测试完善 + 用户文档 + 安装程序

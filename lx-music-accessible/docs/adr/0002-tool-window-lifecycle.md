# 工具窗体采用受主窗体拥有的分层生命周期

设置使用主窗体拥有的模态窗体；音源管理、下载管理、导入个人歌单、歌词、切换音源和使用说明使用主窗体拥有的非模态窗体。每类窗体活动期间只允许一个实例，用户关闭后释放并在下次打开时重建；业务状态由工作流持有。主窗体隐藏到托盘或恢复时，当前工具窗体作为同一窗口组共同隐藏或恢复，以避免孤立窗口、重复订阅和跨窗体焦点竞争。

本轮不持久化工具窗体的尺寸与位置。每次创建时使用默认尺寸并相对主窗体居中，窗体打开期间允许用户调整大小；关闭并重建后恢复默认几何信息，以避免跨显示器后恢复到不可见区域，并控制本轮重构范围。

设置打开时，模态范围覆盖整个应用窗口组；主窗体以及已经打开的下载管理、导入个人歌单窗体均不可交互。模态窗体关闭后，键盘焦点回到此前用于打开它的“工具”菜单入口。

2026-09-28 无障碍复核修订：音源管理从模态改为非模态，与其余工具窗体统一。音源测试、导入和启用是长耗时操作，模态会在此期间屏蔽播放菜单、歌词窗口和下载管理，用户无法边等待边继续播放或查看进度；非模态且同时只允许一个实例，既保留窗口组内的焦点秩序，也让朗读反馈在等待期间继续可达。

用户通过明确的“退出”命令结束应用时，不因活动下载或歌单导入再追加一次确认。统一关闭流程负责阻止新操作、安全取消或收尾活动任务、保存设置与音源状态后退出；不得提交半完成的歌单快照，也不允许任务脱离应用进程继续。该行为与仅关闭工具窗体严格区分。

工具窗体不在内容区提供“关闭”按钮，也不提供只能用鼠标点击、却无法获得键盘焦点的装饰性关闭控件。用户通过原生标题栏关闭、`Alt+F4` 或 `Esc` 进入同一套窗体关闭流程。

导入个人歌单窗体处于歌曲预览层级时，第一次按 `Esc` 只返回歌单列表；回到导入顶层后再次按 `Esc` 才进入窗体关闭流程。若导入仍在进行，关闭流程继续遵循“保留窗体并继续导入”或“取消当前导入并关闭”的显式选择。

音源管理窗体执行网络导入、启用或有效性检测期间仍允许通过原生关闭、`Alt+F4` 或 `Esc` 立即关闭。用户已经明确发起的操作继续由应用完成，最终结果通过全局无障碍播报反馈，重新打开音源管理时显示服务持有的最终状态；本轮不为这些既有音源接口新增取消能力。

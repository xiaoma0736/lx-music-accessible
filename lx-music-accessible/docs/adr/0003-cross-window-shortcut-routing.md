# 播放控制快捷键跨工具窗体路由

可配置的播放、音量和歌词偏移等快捷键在主窗体及工具窗体中统一路由，以保留拆窗前的播放控制能力。焦点位于可编辑文本控件中，或设置窗体正在录制快捷键时，暂停这套路由，避免截获输入。`Alt+1` 至 `Alt+4` 只负责主窗体的页面导航，不从工具窗体触发，也不为已迁出的功能保留 `Alt+5` 至 `Alt+8`。

`Alt+5` 至 `Alt+8` 同时从内置保留键集合中释放；它们没有默认行为，但允许用户主动绑定为可配置快捷键。

主窗体新增“工具(_T)”菜单，依次包含“下载管理(_D)”、“导入个人歌单(_I)”、分隔线、“音源管理(_M)”和“设置(_S)”。这些字母是标准菜单访问键，不构成工具窗体的直接快捷键。

设置窗体处于快捷键录制状态时，第一次按 `Esc` 只取消本次录制并保留窗体；录制状态结束后再次按 `Esc` 才执行设置窗体的关闭流程。

快捷键冲突对话框中的“重新设置”命令可显式打开设置窗体的“快捷键”分类，聚焦冲突项并立即开始录制；这是一条带上下文的修复路径，不是工具窗体直达快捷键。

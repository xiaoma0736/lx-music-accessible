# 落雪音乐无障碍版 使用说明

落雪音乐无障碍版 V2.0（全部功能免费）是一款专为盲人和视障用户优化的 Windows 音乐播放器，基于开源项目 lx-music-desktop 开发。软件支持 NVDA、讲述人、JAWS、争渡、保益悦听等主流屏幕阅读器，全部功能均可通过键盘完成，并提供语音朗读反馈和歌词同步朗读。自 V2.0 起，**全部功能免费开放**，无需任何激活码或赞助解锁；赞助纯属自愿支持（帮助菜单→赞助）。

## 一、软件简介

- **面向盲人与视障用户**：完整支持主流屏幕阅读器与读屏软件。
- **全键盘操作**：所有功能均可通过键盘完成，无需鼠标。
- **语音反馈**：操作状态变化自动朗读，可同步朗读歌词。
- **全部免费**：任何功能都不收费，帮助菜单中的“赞助”仅供自愿支持开发者。

## 二、页面与切换

主窗口共 8 个页面，按 Alt+1 到 Alt+8 快速切换：

| 快捷键 | 页面 |
| --- | --- |
| Alt+1 | 搜索 |
| Alt+2 | 播放列表 |
| Alt+3 | 导入个人歌单 |
| Alt+4 | 分类歌单 |
| Alt+5 | 排行榜 |
| Alt+6 | 设置 |
| Alt+7 | 下载管理 |
| Alt+8 | 音源管理 |

也可使用菜单栏：Alt+B 打开浏览菜单，Alt+T 打开设置菜单，Alt+H 打开帮助菜单。按 Ctrl+R 可刷新当前页面。

歌词已改为独立窗口：在任意歌曲列表中按 Shift+回车，或在歌曲右键菜单选择“查看歌词”，即可打开歌词窗口。歌词窗口内播放局部快捷键（F5~F12、Shift+F7/F8 等）仍然生效，按 ESC 关闭窗口。

## 三、搜索音乐

1. 在搜索页选择音源（全部、网易云、QQ、酷狗、酷我、咪咕）和搜索类型（歌曲、歌手、专辑）。
2. 按 Ctrl+F 将焦点移到搜索框，输入关键词后按回车开始搜索。
3. 结果持续累积显示：首批 20 条，列表末尾有“加载更多”条目，用方向键选择后按回车即可继续加载；结果已自动去重，跨批次不会重复。
4. 在歌曲列表中用上下方向键选择，按回车或空格播放。
5. 搜索历史：在搜索框内按上/下光标可浏览最近 20 条搜索记录（按回车再次搜索）；Ctrl+Delete 删除当前记录，Alt+Delete 清空全部；历史自动保存。
6. 清空搜索：在搜索框内按 Delete 键删除当前全部内容并清空搜索结果（原 ESC 清空已移除）。
7. **V2.0 增强**：单个音源搜索与“全部音源”一样，会按“专辑+歌手+时长”自动去除重复条目；搜索结果只保留“标题/歌手/专辑”包含搜索词的内容，减少无关结果混入。

## 四、播放与控制

播放控制已集成到 Alt 菜单栏的“播放”菜单，无需再用鼠标操作控件。打开“播放”菜单（Alt+P）后按上下方向键选择：播放/暂停、停止、上一首、下一首、快退十秒、快进十秒、音量减、音量加、上一个播放设备、下一个播放设备、歌词延后、歌词提前、播放模式、下载。

窗口聚焦时还支持以下局部快捷键（仅本程序内生效）：

| 快捷键 | 功能 |
| --- | --- |
| F5 | 播放/暂停 |
| F6 | 停止 |
| F7 | 快退十秒 |
| F8 | 快进十秒 |
| F9 | 音量减 |
| F10 | 音量加 |
| F11 | 上一个播放设备 |
| F12 | 下一个播放设备 |
| Shift+F7 | 歌词延后 0.5 秒 |
| Shift+F8 | 歌词提前 0.5 秒 |
| F1 | 切换播放模式（顺序/循环/随机） |
| F2 | 下载当前歌曲 |

- **整列表连续播放**：在搜索、歌单、排行榜、播放列表、收藏列表中播放某首歌曲后，会以整个列表作为播放队列，歌曲播完自动播放下一首；“上一首/下一首”也会在整个列表内切换。也可在歌曲右键菜单选择“从当前歌曲播放整个列表”。
- **自动续播**：搜索结果顺序播放完当前已加载部分后，会自动“加载更多”并继续播放，直至没有更多结果；分类歌单/排行榜等分页列表播放完当前页后会自动加载下一页继续播放，直至最后一页；循环或随机播放模式下不自动续播。
- **用第三方播放器播放**：在“设置→第三方播放器”中配置播放器 exe 路径后，可在任意歌曲列表的右键菜单选择“用第三方播放器播放”，把当前歌曲交由外部播放器（如 PotPlayer、VLC、foobar2000 等）播放；在线歌曲会先下载到本地临时文件再交由播放器，确保各类播放器都能正常播放。

- **切换播放设备**：按“下一个/上一个播放设备”快捷键可在各声卡之间循环切换，正在播放的歌曲会立即切到新设备并继续播放；所选设备会被记住，下次启动自动恢复。
- **音量与音量合成器**：本程序音量与 Windows 音量合成器双向实时同步——用快捷键调音量，合成器立即跟随；直接在音量合成器（任务栏喇叭图标→打开音量合成器）调整，程序内音量也会同步更新（后续热键、切换设备、退出保存都以合成器为准）。

## 四点五、系统托盘

1. 按 ESC 键可随时把主窗口隐藏到系统托盘，音乐继续播放；搜索框有内容时按 ESC 会先清空搜索框，再按一次才隐藏。
2. 双击托盘图标即可恢复主窗口；托盘右键菜单提供：显示主窗口、播放/暂停、上一首、下一首、退出。
3. 也可用“隐藏/显示窗口”快捷键（默认 Ctrl+Shift+H）在后台随时隐藏或恢复窗口，无需再切回本程序。
4. 按 Alt+F4 时是“关闭应用”还是“隐藏到系统托盘”，可在“设置”页“播放设置”中通过“按 Alt+F4 时”下拉框选择（默认关闭应用）。注意：从托盘菜单选择“退出”才会真正结束程序。

## 五、歌词功能

1. 播放歌曲后自动加载歌词，歌词页逐句显示，当前句高亮并自动滚动。
2. 同步朗读：在“设置”页勾选“自动朗读当前歌词”后，播放过程中无论停留在哪个页面，都会随播放进度逐句朗读歌词。
3. 若某首歌的歌词朗读始终偏早或偏晚，可用 Shift+F7（延后）/ Shift+F8（提前）逐次 0.5 秒微调该歌曲的歌词时间偏移，调整会按歌曲记住。
4. 朗读语音和语速可在“设置”页“无障碍设置”中调整。

## 六、歌单与排行榜

1. 分类歌单：在“分类歌单”页先选择分类（语种、风格、场景、情感等），再选择具体歌单，即可查看和播放其中的歌曲。歌曲右键菜单可“收藏整个歌单到在线收藏”。
2. 排行榜：在“排行榜”页选择榜单，回车查看歌曲列表并播放。同样可把整张榜单收藏到在线收藏。
3. 播放列表页分“本地收藏”和“在线收藏”两个选项卡（Alt 切换）。

### 六点五、本地收藏（本地音乐）

1. 在“播放列表”页的“本地收藏”选项卡中，按“添加文件”或“添加文件夹”可把本地音频加入当前选中的本地歌单（默认“我的本地歌曲”）。
2. 可“新建歌单”把喜欢的歌曲分门别类，“重命名歌单”“删除歌单”管理；在歌曲上按 Delete 可从歌单移除。
3. “导出歌单”可把当前歌单导出为 .m3u / .json / .txt 播放列表文件。
4. 本地歌单数据自动保存，重启后仍然保留。

### 六点六、在线收藏（在线音乐）

1. 在搜索、歌单、排行榜的歌曲列表里，用应用键或 Shift+F10 打开操作菜单，选择“添加到收藏”可把当前歌曲加入当前选中的在线歌单（默认“默认收藏”），选择“添加整个列表到收藏”可把整页/整单/整榜一次加入。
2. 在“播放列表”页的“在线收藏”选项卡中可“新建歌单”，把歌曲分到不同歌单；“重命名歌单”“删除歌单”“清空歌单”“从歌单移除”均可操作。
3. “收藏整个歌单到在线收藏”后，打开该歌单时会按需联网加载歌曲列表。
4. 导入各平台账号下的个人歌单：按 Alt+3 或“浏览→导入个人歌单”打开“导入个人歌单”页面，详见“六点七、导入个人歌单”。

### 六点七、导入个人歌单（V1.5 新增，V2.0 起全部功能免费）

本功能已**全部免费开放，无需激活**，直接按以下步骤使用即可。如果你觉得软件有帮助，可在“帮助”菜单选择“赞助”，用手机扫描赞助二维码自愿支持开发者。

**进入方式（任选其一）：**
- 按 Alt+3 直接切换到“导入个人歌单”标签页；
- 按 Alt+B 打开浏览菜单，选择“导入个人歌单”。

**使用步骤：**

1. **选择平台**：页面顶部可切换 网易云 / QQ音乐 / 酷狗音乐 / 酷我音乐。
2. **登录账号**（三种方式任选其一）：
   - **网页登录（推荐，网易云/QQ/酷我通用）**：按“网页登录”按钮，会在软件内打开对应平台的官网登录页面；用键盘在页面中正常登录（和平时用浏览器登录一样）。软件会自动检测登录状态，检测到登录成功后会自动关闭网页并提示“Cookie获取成功”；若自动检测未成功，可按 Tab 到“完成并获取 Cookie”按钮回车，再检测一遍。注意：酷狗不支持网页登录，请改用粘贴Cookie登录或酷狗APP扫码登录。
   - **粘贴Cookie登录（网易云/QQ/酷狗通用）**：先在电脑浏览器登录平台网页版，按 F12 打开开发者工具，在控制台输入 document.cookie 回车，把显示的 Cookie 完整复制粘贴到输入框并提交。注意：酷我不支持粘贴Cookie登录，请改用网页登录。
   - **酷狗APP扫码登录（仅酷狗）**：按“酷狗APP扫码登录”按钮，软件内显示二维码，用酷狗APP扫码并在手机上确认即可。
3. **获取我的歌单**：登录后按“获取我的歌单”，可看到“我喜欢的音乐”、我创建的歌单和我收藏的歌单。
4. **浏览与选择**：按上下方向键浏览歌单；按回车打开该歌单的歌曲预览；按 Ctrl+空格 选中或取消选中（可多选）。
5. **导入**：选中后按“导入所选歌单”批量导入；在歌曲预览页可按“导入此歌单”导入当前歌单，按“返回歌单列表”可返回继续选择。
6. **导入结果**：导入的歌单会保存为“播放列表→在线收藏”下的本地快照歌单，歌曲列表一次性抓取到本地，之后无需联网也能浏览；播放时仍需在线音源解析。
7. **重复导入**：重复导入同一歌单会覆盖更新其中的歌曲，不会产生重复歌单。
8. **安全说明**：登录凭据（Cookie）只保存在本机，使用 Windows DPAPI 加密存储，不会上传到任何第三方服务器，请求直接连接各音乐平台官方接口。

**小提示**：在歌曲预览列表中，回车或空格可直接播放，按应用键或 Shift+F10 打开操作菜单，可把歌曲加入在线收藏。

## 七、下载管理

在“下载管理”页可以查看下载任务，支持取消选中、重试、打开下载文件夹、清空已完成任务。下载目录可在“设置”页中修改。

**批量下载**：在任意歌曲列表的右键菜单中选择“下载整个列表”，可按“默认下载音质”批量下载该列表内的全部在线歌曲；在专辑搜索结果或专辑详情（回车展开专辑）中，右键菜单会出现“下载整张专辑”，可一键下载整张专辑。默认下载音质在“设置→下载设置”中配置；当下载不了所设置的音质时，会自动回退到该音源的最高可用音质。批量下载开始时会播报本次数量，完成时不再逐条播报（失败/取消仍会播报）。

## 八、音源管理

1. 内置音源：网易云、QQ、酷狗、酷我、咪咕，以及随版本固定并校验摘要的备用源，开箱即用；启动时不会联网更新脚本。
2. 自定义音源：支持从网络地址或本地文件导入。导入内容先暂存且不执行；确认来源、版本、SHA-256 摘要和网络权限后，需明确选择“启用”。
3. 在“音源管理”页可对音源执行设为默认、启用、禁用、检测有效性、重命名、删除等操作（应用键或 Shift+F10 打开操作菜单）。旧版远程脚本升级后会保留但默认禁用。

## 九、设置

1. **常规设置**：默认音量、自动播放、随机播放、循环播放、默认音质、默认下载音质（单曲/批量/专辑下载使用，下载不了时自动回退最高音质）、下载目录、第三方播放器（歌曲右键菜单“用第三方播放器播放”用它播放）。
2. **无障碍设置**：
   - 启用屏幕阅读器支持：默认开启。
   - 启用语音朗读提示：控制操作反馈是否朗读。
   - 朗读后端：自动检测，按“保益→争渡→读屏(Prism)→SAPI”优先选择当前可用的后端（保益悦听运行时优先用保益），无需手动设置。
   - 备注：检测到 NVDA 读屏运行时，朗读会自动回退到 SAPI5 保底，保证语音提示始终可听。
   - 朗读语音：下拉框第一项为“自动检测（推荐）”；选择具体的 SAPI5 语音（如 Microsoft Huihui Desktop）后，朗读由该语音直接发声，用于无读屏时的兜底。
   - 朗读语速：慢、标准、快三档。
3. **快捷键设置**：列表同时包含“全局快捷键”和“局部快捷键”（名称带“（局部）”，仅本程序内生效）。选中列表项后按回车，会提示“请按下快捷键”，此时按下新的组合键；设置完成后会弹出确认对话框，按回车或确定关闭后回到列表。按 Delete 清除，按 Esc 取消修改，也可一键恢复默认。

## 十一、常见问题

1. **没有语音提示？** 检查“设置”页是否勾选了“启用语音朗读提示”；确认系统安装了语音包（中文语音如 Microsoft Huihui）；如果使用了读屏，请确认读屏正在运行。
2. **朗读后端显示为 SAPI？** 说明未检测到争渡、保益或 Prism 可用的读屏后端，程序使用系统语音兜底。
3. **朗读语音列表里没有 SAPI5 语音？** 说明系统中未安装对应的 SAPI 语音包，可在 Windows 的语音设置中添加。
4. **搜索没有结果？** 检查网络连接，或切换其他音源重试。
5. **歌曲无法播放？** 多为音源或网络问题，可换一个音源或重新搜索再试；也可在音源管理中检测音源有效性。
6. **导入个人歌单登录失败？** 确认登录方式与平台匹配（酷狗用粘贴Cookie或APP扫码，酷我用网页登录）；Cookie 登录时请确保复制的 Cookie 完整，且浏览器已登录对应平台。

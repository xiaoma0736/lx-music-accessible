# 落雪音乐无障碍版 使用说明

落雪音乐无障碍版 3.0.0（全部功能免费）是一款专为盲人和视障用户优化的 64 位 Windows 音乐播放器，基于开源项目 lx-music-desktop 开发，采用 .NET Framework 4.8 与原生 WinForms。软件提供 NVDA、讲述人、JAWS、争渡、保益悦听等读屏器所需的 UIA 语义，状态通知由 TTS 统一输出，全部功能均可通过键盘完成，并提供语音朗读反馈和歌词同步朗读。**全部功能免费开放**，无需任何激活码或赞助解锁；赞助纯属自愿支持（帮助菜单→赞助）。

**系统要求：** 64 位 Windows；Microsoft .NET Framework 4.8 或更新版本；使用网页登录时需要 Microsoft Edge WebView2 Runtime。安装程序会检测 .NET Framework 4.8，缺失时会显示官方下载地址，并在 `%LocalAppData%\LXMusicAccessible\setup\net48-diagnostics.txt` 记录诊断。升级覆盖安装不会重置 `%LocalAppData%\lxmusic` 中的设置、歌单、登录凭据、快捷键和可信音源。

## 一、软件简介

- **面向盲人与视障用户**：提供原生 WinForms UIA 语义和焦点行为，状态通知由 TTS 输出。
- **全键盘操作**：所有功能均可通过键盘完成，无需鼠标。
- **语音反馈**：默认朗读正在播放与播放失败、暂停/停止/恢复、切歌、快进快退位置、音量、窗口显隐、播放模式、播放设备、下载结果、收藏、导入、登录、设置、快捷键录制、错误，以及可选的逐句歌词；常规浏览与加载回显、返回上级列表、音源窗口自己命令后的列表更新回显、使用说明的章节切换、歌单预览的成功提示和欢迎语保持安静。工具菜单里的“语音播报”和“歌词播报”是带勾选的状态项，可随时开关：“语音播报”关掉后，除逐句歌词以外的提示都不再朗读；逐句歌词只由“歌词播报”决定。设置里的“语音提示范围”可单独关闭播放状态、切歌、音量、快进快退、窗口显隐、播放模式和播放设备。每一条提示同时写进主窗口底部的播报行，关掉朗读后仍可用读屏器的审阅光标查看或由放大工具阅读。
- **全部免费**：任何功能都不收费，帮助菜单中的“赞助”仅供自愿支持开发者。

## 二、页面与切换

主窗口只包含 4 个音乐浏览页面；页面下方还有一条播报行显示最近一次提示的文字，最底部是包含正在播放信息的状态栏，两者都不属于页面。按 Ctrl+1 到 Ctrl+4 快速切换：

| 快捷键 | 页面 |
| --- | --- |
| Ctrl+1 | 搜索 |
| Ctrl+2 | 播放列表 |
| Ctrl+3 | 分类歌单 |
| Ctrl+4 | 排行榜 |

Ctrl+5 到 Ctrl+8 依次打开下载管理、导入个人歌单、音源管理和设置；歌词窗口不使用数字切换。也可使用菜单栏：按 Alt 进入菜单栏后用左右方向键选择，或用访问键直接打开——Alt+F 文件、Alt+B 播放、Alt+D 导航、Alt+T 工具、Alt+H 帮助。本应用默认把 F10 用作“音量加”，所以 F10 不承担打开菜单的功能，可在“工具→设置→快捷键”中改键。工具菜单依次提供“工具→下载管理”“工具→导入个人歌单”、分隔线、“工具→音源管理”和“工具→设置”，四项功能没有其他重复入口。按 Ctrl+R 可刷新当前页面。页面内容只在明确命令时加载：用 Ctrl+1 到 Ctrl+4 或“导航”菜单打开某页时加载这一页的首层数据，用 Ctrl+R 或页内“刷新”按钮重新加载；用方向键或 Ctrl+Tab 在标签之间移动焦点不会发起请求、不会清空列表，也不会播报。

歌词已改为独立窗口：在任意歌曲列表中按 Shift+回车，或在歌曲右键菜单选择“查看歌词”，即可打开歌词窗口。歌词窗口以全文文本查看器显示整首歌词，句首不再添加序号（序号会被读屏器当作正文反复朗读）；当前句按“设置→歌词→自动滚动歌词”决定是否高亮并滚动跟随播放进度；关掉该项时窗口保持你手动放好的阅读位置，可用上下方向键逐行阅读、PageUp/PageDown 翻页。按“复制歌词”按钮或 Ctrl+Shift+C 可一键把整首歌词复制到剪贴板。歌词窗口内播放局部快捷键（F5~F12、Shift+F7/F8 等）仍然生效，按 ESC 关闭窗口。歌词窗口同时只开一个：对另一首歌再按一次 Shift+回车，会把已有窗口带到前台并载入这首歌的歌词，不会出现两个同名窗口。

## 三、搜索音乐

1. 在搜索页选择音源（全部、网易云、QQ、酷狗、酷我、咪咕）和搜索类型（歌曲、歌手、专辑）。
2. 按 Ctrl+F 将焦点移到搜索框，输入关键词后按回车开始搜索。
3. 结果持续累积显示：首批 20 条。搜索、专辑、收藏歌单、分类歌单、分类歌曲和榜单歌曲等分页列表末尾有“加载更多”条目，用方向键选择后按回车或双击即可继续加载；在专辑歌曲、分类歌单歌曲、榜单歌曲或收藏歌曲列表按 Backspace 可返回上级列表。成功追加后焦点和读屏光标移动到新增的第一首。结果已自动去重，跨批次不会重复。
4. 歌曲列表保持单选。按回车播放焦点歌曲；按空格暂停正在播放的歌、恢复暂停的歌，或在没有当前歌曲时播放焦点歌曲。
5. 搜索历史：在搜索框内按上/下光标可浏览最近 20 条搜索记录（按回车再次搜索）；Ctrl+Delete 删除当前记录，Alt+Delete 清空全部；历史自动保存。
6. 清空搜索：在搜索框内按 Delete 键删除当前全部内容并清空搜索结果（原 ESC 清空已移除）。
7. **V2.0 增强**：单个音源搜索与“全部音源”一样，会按“专辑+歌手+时长”自动去除重复条目；搜索结果只保留“标题/歌手/专辑”包含搜索词的内容，减少无关结果混入。

## 四、播放与控制

播放控制已集成到 Alt 菜单栏的“播放”菜单，无需再用鼠标操作控件。打开“播放”菜单（Alt+B）后按上下方向键选择：播放/暂停、停止、上一首、下一首、快退十秒、快进十秒、音量减、音量加、上一个播放设备、下一个播放设备、切换播放模式、下载当前歌曲。菜单项右侧标出的按键（如 F6 停止、F3 上一首）就是默认局部快捷键，可直接按，“音量加”因保留 F10 给菜单键而只在文字里注明（默认 F10）；菜单文字括号里的字母（如“停止(&S)”）只在该菜单已经打开时有效。

窗口聚焦时还支持以下局部快捷键（仅本程序内生效）：

| 快捷键 | 功能 |
| --- | --- |
| F5 | 播放/暂停 |
| F6 | 停止 |
| F3 | 上一首 |
| F4 | 下一首 |
| F7 | 快退十秒 |
| F8 | 快进十秒 |
| F9 | 音量减 |
| F10 | 音量加 |
| F11 | 上一个播放设备 |
| F12 | 下一个播放设备 |
| Shift+F7 | 歌词延后 0.5 秒 |
| Shift+F8 | 歌词提前 0.5 秒 |
| F1 | 切换播放模式（顺序/循环/随机） |
| F2 | 下载当前歌曲 |

- **整列表连续播放**：在搜索、歌单、排行榜、播放列表、收藏列表中播放某首歌曲后，会以整个列表作为播放队列，歌曲播完自动播放下一首；“上一首/下一首”也会在整个列表内切换。任意歌曲列表的右键菜单提供：播放、查看歌词、查看详情、收藏歌曲、下载当前歌曲、下载单曲音质、播放音质、下载整张专辑、批量选择下载、切换音源播放、用第三方播放器播放。
- **自动续播**：搜索结果顺序播放完当前已加载部分后，会自动“加载更多”并继续播放，直至没有更多结果；分类歌单/排行榜等分页列表播放完当前页后会自动加载下一页继续播放，直至最后一页；循环或随机播放模式下不自动续播。
- **用第三方播放器播放**：在“工具→设置→播放”中配置播放器 exe 路径后，可在任意歌曲列表的右键菜单选择“用第三方播放器播放”，把当前歌曲交由外部播放器（如 PotPlayer、VLC、foobar2000 等）播放；在线歌曲会先下载到本地临时文件再交由播放器，确保各类播放器都能正常播放。

常用全局快捷键（程序在后台也能用）：

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+Home | 播放/暂停 |
| Ctrl+Alt+End | 停止 |
| Ctrl+Alt+PageUp | 上一首 |
| Ctrl+Alt+PageDown | 下一首 |
| Ctrl+Alt+Left | 快退 |
| Ctrl+Alt+Right | 快进 |
| Ctrl+Alt+Up | 音量加 |

以上快捷键（含局部快捷键）均可在“工具→设置→快捷键”中修改或恢复默认。局部播放快捷键在主窗口和工具窗口中都可使用；编辑文本或录制快捷键时不会触发播放命令。

- **切换播放设备**：按“下一个/上一个播放设备”快捷键可在各声卡之间循环切换，正在播放的歌曲会立即切到新设备并继续播放；所选设备会被记住，下次启动自动恢复。
- **音量与音量合成器**：本程序音量与 Windows 音量合成器双向实时同步——用快捷键调音量，合成器立即跟随；直接在音量合成器（任务栏喇叭图标→打开音量合成器）调整，程序内音量也会同步更新（后续热键、切换设备、退出保存都以合成器为准）。

## 四点五、系统托盘

1. 按 ESC 键可随时把主窗口隐藏到系统托盘，音乐继续播放；搜索框有内容时按 ESC 会先清空搜索框，再按一次才隐藏。
2. 双击托盘图标即可恢复主窗口；托盘菜单（右键或应用键打开）提供：显示主窗口（Alt+S）、播放/暂停（Alt+P）、上一首（Alt+V）、下一首（Alt+N）、退出（Alt+X）。菜单打开后按这些访问键即可直接执行，无需移动鼠标。
3. 可在“工具→设置→快捷键”中自定义全局“隐藏/显示窗口”快捷键，默认为 Ctrl+Alt+H；“文件”菜单里的同名项也标出了这个按键。本程序不占用 Ctrl+H，那是文本框里删除前一个字符的通用按键，所以在搜索框内输入时不会误把整个窗口藏起来。
4. 按 Alt+F4 时是“关闭应用”还是“隐藏到系统托盘”，可在“工具→设置→常规”中通过“按 Alt+F4 时”下拉框选择（默认关闭应用）。注意：从托盘菜单选择“退出”才会真正结束程序。

## 五、歌词功能
1. 播放歌曲后自动加载歌词，歌词窗口以全文文本查看器显示整首歌词，句首没有序号；当前句高亮并自动滚动跟随播放进度，按 Ctrl+Shift+C 或“复制歌词”按钮可以把全文复制到剪贴板。
2. 同步朗读：在“工具→设置→歌词”中勾选“自动朗读当前歌词”后，播放过程中无论停留在哪个页面，都会随播放进度逐句朗读歌词。
3. 若某首歌的歌词朗读始终偏早或偏晚，可用 Shift+F7（延后）/ Shift+F8（提前）逐次 0.5 秒微调该歌曲的歌词时间偏移，调整会按歌曲记住。
4. 朗读语音、语速和提示范围可在“工具→设置→无障碍”中调整；提示范围默认全部开启。

## 六、歌单与排行榜

1. 分类歌单：支持网易云、QQ音乐、酷狗、酷我、咪咕五个官方平台。用 Ctrl+3 或“导航→分类歌单”打开本页时自动加载当前平台分类；换平台后可用页内“刷新”按钮或 Ctrl+R 重新加载。选择分类后按回车加载歌单列表，再选择歌单并回车查看歌曲。分页统一使用列表末尾的“加载更多”条目：把它选为当前项后按回车或双击就追加下一页，界面上没有“上一页/下一页”按钮。在“歌单”列表上打开右键菜单可“收藏整个歌单到在线收藏”，“分类歌曲”列表使用下面的歌曲通用菜单。
2. 排行榜：支持网易云、QQ音乐、酷狗、酷我、咪咕五个官方平台。用 Ctrl+4 或“导航→排行榜”打开本页时自动加载当前平台榜单；选择榜单后按回车加载歌曲列表，在歌曲上再按回车播放，列表末尾同样用“加载更多”条目追加下一页。在“排行榜”列表上打开右键菜单可“收藏整个榜单到在线收藏”。
3. “播放列表”不是选项卡集合，而是一个页面：左侧“我的歌单”列表，右侧“收藏歌曲”列表，两者之间用 Tab 或 Shift+Tab 移动焦点。

### 六点五、播放列表页（收藏歌单）

1. “播放列表”页用于浏览已经收进在线收藏的歌单：先在“我的歌单”里选择一项，按回车把它的歌曲读进右侧“收藏歌曲”列表；收藏有变化或换了音源时按“刷新”。
2. 页顶按钮依次是：新建歌单、重命名歌单、删除歌单、刷新、移除歌曲、清空歌曲。全部要先用 Tab 到达再按回车执行，焦点经过时不会自动执行。
3. “收藏歌曲”列表里按回车或空格播放，整张列表成为队列；歌曲较多时列表末尾出现“加载更多”条目，选中后按回车追加下一页。
4. 本地音频不需要建库：用“文件→打开本地文件”选择文件即可直接播放，关闭应用不会保留为歌单。

### 六点六、在线收藏（在线音乐）

1. 在搜索、分类歌单、排行榜和专辑的任何歌曲列表里，用应用键或 Shift+F10 打开歌曲菜单：播放、查看歌词、查看详情、收藏歌曲、下载当前歌曲、下载单曲音质、播放音质、下载整张专辑、批量选择下载、切换音源播放、用第三方播放器播放。“收藏歌曲”把当前选中的一首歌加入在线收藏。
2. 在“播放列表”页可用“新建歌单”把收藏分到不同歌单；“重命名歌单”“删除歌单”改名与删除，“清空歌曲”清空当前歌单的全部歌曲，“移除歌曲”只移除当前选中的一首。
3. 在“分类歌单”页的“歌单”列表或“排行榜”页的榜单列表上使用右键菜单，可以把整张歌单或整张榜单收进在线收藏；之后在“播放列表”页选中它并按回车即可联网加载歌曲。
4. 导入各平台账号下的个人歌单：从“工具→导入个人歌单”打开独立窗口，详见“六点七、导入个人歌单”。

### 六点七、导入个人歌单（V1.5 新增，V2.0 起全部功能免费）

本功能已**全部免费开放，无需激活**，直接按以下步骤使用即可。如果你觉得软件有帮助，可在“帮助”菜单选择“赞助”，用手机扫描赞助二维码自愿支持开发者。

**进入方式：**按 Alt+T 打开工具菜单，选择“导入个人歌单”。该功能没有 Alt+数字直达键，也不在浏览菜单中重复出现。

**使用步骤：**

1. **选择平台**：按下“网易云音乐”“QQ音乐”“酷狗音乐”或“酷我音乐”按钮后，软件会先检测本机已保存的登录状态。检测有效时直接加载并聚焦“个人歌单”，不会重复提示登录；没有保存登录或登录已失效时，才打开该平台的“登录方式”窗体。
2. **选择登录方式（仅在需要登录时出现）**：登录方式列表会聚焦第一项；用上下方向键浏览，按回车或“使用所选方式”确认，按 Esc 或 Alt+F4 取消。
   - **网页登录（四个平台都有）**：会在软件内打开该平台的官网登录页面，焦点自动落进网页；在页面里像平常一样登录（扫码、输密码或用手机确认都可以）。软件每两秒检查一次该平台的登录 Cookie，一旦检测到就自动向平台确认并关闭网页，不需要你去找确认按钮。浏览器的登录状态会保留，所以**这个平台先前在网页里已经登录过时，窗口打开两三秒后就会自动确认并关闭，直接按回车即可**，不用再扫一次码。若平台没有确认这次登录，软件会播报一次并在状态行说明原因：可以按“刷新页面”重新检测，或按“完成登录”手动再试一次，也可以改用粘贴 Cookie 登录。页面多次跳转只会说明一次。
   - **换账号请按“清除登录记录”**：正因为网页登录会沿用浏览器里已有的登录状态，要改用另一个账号时必须先丢掉旧状态。网页登录窗口上方第三个按钮就是“清除登录记录”：按回车后软件会清掉本程序浏览器里的登录 Cookie、重新打开该平台登录页并播报一次，再在页面里登录新账号即可。这一步不会删除软件已经保存的账号，也不影响粘贴 Cookie 登录。
   - **粘贴 Cookie 登录（四个平台都有）**：确认后会回到导入窗体并聚焦 Cookie 输入框；粘贴从浏览器复制的完整 Cookie 后按“使用 Cookie 登录”。
   - **酷狗 APP 扫码登录（仅酷狗额外提供）**：软件内显示二维码，用酷狗 APP 扫码并在手机上确认；二维码获取失败或过期时按提示用“刷新二维码”重试。
   - 四个平台的选择顺序固定为：网页登录、粘贴 Cookie 登录，酷狗再多一项 APP 扫码登录。各平台官网登录页里自带的扫码、短信、密码登录在网页登录中同样可用。
3. **加载歌单**：登录成功后会自动加载个人歌单，并把焦点放到“个人歌单”列表；可看到“我喜欢的音乐”、我创建的歌单和我收藏的歌单。取消登录方式选择、或登录没有被平台确认时，焦点回到刚才按下的平台按钮，原样再按一次就能重来。若状态检测或读取失败，仍可用“加载歌单”重试；酷我音乐的个人歌单由服务端公开接口按账号读取，必要时可再按一次。
4. **浏览与选择**：按上下方向键浏览“个人歌单”列表；按回车打开该歌单的“歌曲预览”列表。
5. **导入**：按“导入当前歌单”导入正在预览的这一张歌单；一次只导入一张，导入进度与结果会逐张播报；按“返回歌单列表”回到左侧继续选择下一张。
6. **导入结果**：导入的歌单会保存为“播放列表→在线收藏”下的本地快照歌单，歌曲列表一次性抓取到本地，之后无需联网也能浏览；播放时仍需在线音源解析。
7. **重复导入**：重复导入同一歌单会覆盖更新其中的歌曲，不会产生重复歌单。
8. **安全说明**：登录凭据（Cookie）只保存在本机，使用 Windows DPAPI 加密存储，不会上传到任何第三方服务器，请求直接连接各音乐平台官方接口。

**小提示**：在“歌曲预览”列表中按回车播放当前歌曲，按 Shift+回车查看这首歌的歌词，按应用键或 Shift+F10 打开与主窗口相同的歌曲通用菜单（收藏歌曲、下载等）。导入只用“导入当前歌单”一个按钮，不会由回车触发：导入服务一次只能导入整张远程歌单，因此界面不提供“全选歌曲”“导入选中歌曲”这类无法真正按所选歌曲导入的命令。预览中第一次按 Esc 返回歌单列表，再按 Esc 才关闭窗口。导入进行中关闭时，可选择继续导入，或取消并等待当前歌单安全回滚后关闭。

## 七、下载管理

从“工具→下载管理”打开独立窗口查看下载任务。任务列表即使为空也会获得初始焦点。页顶按钮依次是“取消”“重试”“打开文件夹”“清除已完成”：前两个只在所选任务处于可取消或可重试状态时可用，可用状态会随任务进展自动更新，如果更新时你正停在那个按钮上，焦点会回到任务列表而不会丢失；“清除已完成”只移除已完成、失败和已取消任务。按 Esc 或 Alt+F4 关闭窗口不会取消活动下载，重新打开仍显示应用持有的最新任务。下载目录可在“工具→设置→下载”中修改。

**下载当前歌曲**：在歌曲菜单选择“下载当前歌曲”，或按 F2，会按“默认下载音质”下载当前歌曲。“下载单曲音质”和“播放音质”是两个内容相同的子菜单，只列出当前默认音源声明提供的音质，接口没有的音质不会出现；条目会注明“实际 无损 FLAC”之类的真实媒质，下载时按该实际音质保存，不会先下载一份不达标的文件。默认音源不支持当前歌曲平台时回退到该平台的全部接口；在音源管理里改默认音源后，子菜单立即按新音源探测。在专辑上下文中可用“下载整张专辑”；专辑下载和批量下载都使用设置中的“默认下载音质”。

**批量选择下载**：在搜索结果、收藏歌曲、歌单歌曲或排行榜歌曲打开“批量选择下载”。独立窗口列出当前已加载歌曲；“批量下载歌曲”列表中 `空格` 只勾选或取消当前行，`Ctrl+A` 全选，“清空”取消全部，状态行显示“已选择 N 首”。按“下载选中歌曲”显式创建任务；`Enter` 不下载，方向键和勾选不联网。窗口关闭后焦点回到发起列表。下载进度和结果由下载管理播报。

## 八、音源管理

1. 内置音源：网易云、QQ、酷狗、酷我、咪咕，以及随版本固定并校验摘要的备用源，开箱即用。窗口显示后会在后台刷新产品内置的 HYW、聚合 API、全豆要和念心 4 个固定订阅；刷新失败时继续使用上一有效版本。
2. 自定义音源：支持从网络地址或本地文件导入。用户主动导入的有效内容会在脚本与摘要校验通过后自动信任、启用并保存；校验失败的内容不会执行。
3. 在“工具→音源管理”打开的独立窗口中，可对音源执行设为默认、启用、禁用、测试、检查更新、删除等操作（应用键、Shift+F10 打开操作菜单；在音源列表上按回车或空格也会弹出同一个菜单）。音源列表即使为空也会获得初始焦点。按 Esc 或 Alt+F4 可关闭窗口；已经明确发起的操作继续在后台完成并播报结果。旧版缺失信任元数据的有效音源会自动迁移并启用；用户后来明确禁用的可信音源保持禁用。“测试”检测音源能否正常出歌；“检查更新”重新拉取该音源的接口内容并保留音源标识与配置。当前版本不提供重命名音源。

4. **切换音源播放**：歌曲菜单中的“切换音源播放”窗口会查询所有已启用接口，并为每个声明支持的音质生成候选；列表只显示解析到可播放链接的结果，状态行显示“找到 N 个可播放音源，已隐藏 M 个不可用项”。播放严格使用你选择的音源和音质，不会静默改成另一个候选。查询在后台分批进行，窗口保持可用：状态行显示“正在查询可用的音源，请稍候”，再次执行搜索会取消上一轮；查询超时只列出已经确认的可播放项，并提示重新查询。

## 九、设置

从“工具→设置”（Ctrl+8）打开设置窗口。窗口顶部是名为“设置分类”的选项卡，每次普通打开都停在“常规”。在选项卡上用左右方向键或 Ctrl+Tab 切换分类——切换分类只换可见页面，不会保存也不会联网；按 Tab 进入该分类的内容，按 Shift+Tab 回到选项卡。七类依次为：常规、播放、歌词、下载、存储与缓存、无障碍、快捷键。

- **常规**：按 Alt+F4 时关闭应用或隐藏到托盘。
- **播放**：默认播放音质、顺序播放/列表循环/单曲循环/随机播放四值默认模式，以及第三方播放器路径；手工输入的路径按 Enter 写入设置。
- **歌词**：“自动朗读当前歌词”随播放进度逐句朗读；“自动滚动歌词”控制歌词窗口是否把选中位置拉到正在唱的那一句——开启时跟随播放，关闭后窗口保持你在歌词里放的阅读位置，可以往前或往后读，当前句仍可由逐句朗读报出。切换设置立即生效。
- **下载**：目录、默认音质、歌词、音质后缀和歌曲命名顺序。
- **存储与缓存**：数据目录迁移和显式清理缓存。
- **无障碍**：语音播报开关（除逐句歌词以外全部提示的总开关）、当前朗读后端、朗读语音、朗读语速和“语音提示范围”复选框组。范围包括播放状态、切歌播报、音量变化、快进快退位置、窗口显隐、播放模式、播放设备，默认全部开启；改动立即保存。切换朗读语音或语速后立即生效，窗口下次打开时仍选中你保存的那一项（列表第一项“自动检测（推荐）”表示由后端自行选择语音）。屏幕阅读器语义始终启用，不提供关闭开关。
- **快捷键**：全局与局部快捷键的录制、清除和恢复默认。录制中第一次按 Esc 只取消录制，再按 Esc 才关闭设置。

普通修改立即生效，关闭设置时保存。第三方播放器路径和下载目录只在按 Enter 或关闭窗口时写入，Tab 或点击别处不会写入半截内容；无效路径会阻止关闭并把焦点放回输入框。设置窗口是模态窗口；音源管理、下载管理和导入个人歌单是非模态窗口，打开它们时仍能继续播放并操作主窗口。每类工具窗口同时只存在一个：重复执行同一个命令会把已经打开的窗口带到前台（歌词窗口还会顺带载入新选的歌曲），不会出现两个同名窗口互相竞争焦点。所有工具窗口都可用原生标题栏、Esc 或 Alt+F4 关闭，内容区不另设关闭按钮。

## 十一、常见问题

1. **没有语音提示？** 检查“工具→设置→无障碍”中是否启用了语音播报；确认系统安装了语音包（中文语音如 Microsoft Huihui）；如果使用了读屏，请确认读屏正在运行。
2. **朗读后端显示为 SAPI？** 说明未检测到争渡、保益或 Prism 可用的读屏后端，程序使用系统语音兜底。
3. **朗读语音列表里没有 SAPI5 语音？** 说明系统中未安装对应的 SAPI 语音包，可在 Windows 的语音设置中添加。
4. **搜索没有结果？** 检查网络连接，或切换其他音源重试。
5. **歌曲无法播放？** 多为音源或网络问题，可换一个音源或重新搜索再试；也可在音源管理中检测音源有效性。
6. **导入个人歌单登录失败？** 四个平台都可以用网页登录或粘贴 Cookie，酷狗还可以用 APP 扫码。网页登录后没有自动关闭，说明平台没有确认这次会话：按“刷新页面”重新检测、按“完成登录”再试一次，或改用粘贴 Cookie。Cookie 登录时请确保复制的 Cookie 完整（网易云需要 MUSIC_U，QQ 需要 uin 与 qm_keyst 或 qqmusic_key，酷狗需要 KugooID 与 t（酷狗 APP 扫码则是 userid 与 token），酷我需要 userid 与 websid），且复制它的浏览器已经登录对应平台。
7. **按播放、暂停、停止、音量或快进键时没有朗读？** 先检查“语音播报”总开关，再到“工具→设置→无障碍→语音提示范围”确认对应类别是否已勾选。这些范围默认开启；关闭后提示仍写入主窗口底部的播报行，但不再语音打断。错误结果始终会朗读。
8. **按 F10 打不开菜单？** 本应用把 F10 默认用作“音量加”。请按 Alt 进入菜单栏，或用 Alt+F、Alt+B、Alt+D、Alt+T、Alt+H 直接打开文件、播放、导航、工具、帮助；也可以在“工具→设置→快捷键”里把“音量加”改到别的键。
9. **切换到某页后列表是空的？** 用方向键或 Ctrl+Tab 移动标签焦点不会自动联网（这是为了避免翻页式浏览时突然发出请求）。请按 Ctrl+1 到 Ctrl+4 打开页面，或用页内“刷新”按钮、Ctrl+R 明确加载。
10. **关掉语音播报后还能看到提示吗？** 能。每一条提示都原样显示在主窗口页面下方的播报行里，可用读屏器的审阅光标逐行查看，也可以用 Windows 放大镜阅读；正在播放的信息始终在底部状态栏。
